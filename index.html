Mise en place (une fois, ≈ 10 min)

  1. Crée un projet gratuit sur supabase.com, région Europe (Paris ou Francfort).
  2. Base de données : SQL Editor → New query → colle le script, puis Run.
  3. Connexion Google : Authentication → Sign In / Providers → Google → active, puis colle l’ID client et le code secret de ton client OAuth Google Cloud. Dans Google Cloud, ajoute à ce client l’URI de redirection indiquée par Supabase (https://xxxx.supabase.co/auth/v1/callback).
  4. Adresses autorisées : Authentication → URL Configuration → Site URL et Redirect URLs :
  5. Clés : Project Settings → API → copie l’URL du projet et la clé anon / publishable ici (jamais la clé service_role).

Gratuit (palier gratuit Supabase : 500 Mo de base, 1 Go de fichiers ≈ 90 h d’audio compressé). Le projet se met en pause après 7 jours sans aucune utilisation : on le relance d’un clic dans le tableau de bord Supabase.

Aide

Les réponses aux questions les plus courantes.

Comment enregistrer une réunion ?

Accueil → Nouvelle transcription, puis le gros bouton rouge. À l’arrêt, la transcription démarre toute seule. En salle, choisis « Ma voix » ; en visio, « Voix + visio » pour entendre tous les participants.

Comment transcrire une visio Teams, Meet ou Zoom ?

Choisis « Voix + visio ». Au démarrage, le navigateur te demande quoi partager : prends l’onglet de la visio (ou « Écran entier » pour l’appli Teams / Zoom) et coche Partager l’audio.

Garder la vidéo de l’écran d’une visio ?

En « Voix + visio » ou « Visio seule », active Garder la vidéo de l’écran. Dans le projet, l’écran enregistré s’affiche à droite et suit la lecture : clique sur une phrase pour revoir la slide ou la maquette montrée à ce moment. Environ 150 Mo par heure, sauvegardés dans ton Google Drive si tu es connecté (tu peux ensuite libérer la place sur ce PC). Préviens les participants.

Quel modèle choisir ?

Laisse le réglage automatique : il choisit selon ton PC. Sans carte graphique, « Rapide » ou « Équilibré » ; avec une carte graphique, « Précis ». Détails dans la page Modèles.

Comment savoir qui parle ?

Après la transcription, les voix sont comparées et chaque phrase reçoit une couleur. Clique sur « Personne 1 » pour la renommer : sa voix est alors mémorisée et elle sera reconnue toute seule aux réunions suivantes (Paramètres → Voix connues).

À quoi sert l’onglet Actions ?

Il relève les décisions (« on valide », « on part sur ») et les actions (« tu peux… », « je m’en occupe »), avec le responsable et l’échéance. Coche ce qui est fait ; pour un relevé reformulé, « Affiner avec une IA ».

Mes données sont-elles envoyées quelque part ?

Non : l’audio et la transcription restent sur ton appareil. Deux exceptions, seulement si tu le demandes : la sauvegarde dans ton Google Drive (compte Google) et l’envoi du texte à l’IA que tu choisis : Claude, Copilot, ChatGPT ou Gemini (« Résumer avec une IA »). Politique de confidentialité

Comment marche l’assistant ?

Il cherche d’abord les passages utiles dans tes réunions (décisions, actions, extraits), puis un modèle de langage rédige la réponse en citant ses sources (les petits numéros, cliquables). Par défaut, ce modèle tourne sur ton appareil (Qwen3, téléchargé une fois) : rien n’est envoyé. Sans carte graphique, une réponse prend de 20 s à 1 min. Pour des réponses plus fines, choisis Claude avec ta clé API dans Paramètres → Assistant IA.

Changer le fond d’écran ?

Page Personnalisation : choisis un fond ou importe ta propre image, puis règle le flou, l’assombrissement et l’opacité des panneaux.

Installer l’appli sur l’ordinateur ou le téléphone ?

Ordinateur (Chrome, Edge) : bouton « Installer l’appli » en haut. Android : menu ⋮ → « Installer l’application ». iPhone (Safari) : Partager → « Sur l’écran d’accueil ».

Raccourcis clavier

Ctrl+K rechercher · Espace pause / lecture · Ctrl+Entrée transcrire · Ctrl+F chercher dans le texte · Échap fermer.
